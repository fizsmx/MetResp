🧠 Entrada Inteligente

Pega o escribe el enunciado completo del ejercicio tal como te lo dieron. El sistema detectará automáticamente el método, la función, los valores iniciales y la tolerancia.
Ejemplos: "Aplicar el método de Newton-Raphson para f(x) = e^x - 2 + x² con x₀ = 0 y error 0.01"

Método de Newton-Raphson

Fórmula: xi+1 = xi − f(xi) / f'(xi)

Error: ea = |xi+1 − xi| / |xi+1| × 100%

Método de Bisección

Punto medio: m = (a + b) / 2

Si f(a)·f(m) < 0 → raíz en [a, m]. Si f(a)·f(m) > 0 → raíz en [m, b].

Error: e = (b − a) / 2

Método de Punto Fijo

Fórmula: xi+1 = g(xi)

Error: ea = |xi+1 − xi| / |xi+1| × 100%

Método de Gauss-Jordan

Reduce la matriz aumentada a forma escalonada reducida (identidad).

Operaciones: intercambio de filas, escalamiento, eliminación.
